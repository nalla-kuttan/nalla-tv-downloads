# Nalla TV downloads

Get the latest apps from [Releases](https://github.com/nalla-kuttan/nalla-tv-downloads/releases/latest).

Each app opens Nalla TV (https://rubans-tv.vercel.app) in its own window and blocks the video players' ads, pop-ups and redirects. Sign in with your Nalla TV account once it opens.

| Device | File | Install |
| --- | --- | --- |
| Android phone, tablet or TV (Android 8+) | `nalla-tv.apk` | Open it on the device and allow installs from that app when Android asks. On a TV, use an app like Send Files to TV, or `adb install nalla-tv.apk`. |
| iPhone or iPad (iOS 16.4+) | `nalla-tv.ipa` | Unsigned. Install it from a Mac or PC with Sideloadly or AltStore using your own Apple ID, then trust it in Settings → General → VPN & Device Management. With a free Apple ID, re-sign it every 7 days. |
| Mac (macOS 13+, Apple silicon and Intel) | `Nalla-TV.dmg` | Drag Nalla TV to Applications and open it. When macOS says it can't verify the app, click Done, then go to System Settings → Privacy & Security and click Open Anyway. |
| Windows 10 or 11 (64-bit) | `Nalla-TV-windows-x64.zip` | Extract it, open the `Nalla TV-win32-x64` folder and run Nalla TV.exe. When SmartScreen warns, choose More info → Run anyway. |

The apps aren't signed by Apple or Microsoft, which is why each system warns the first time.
